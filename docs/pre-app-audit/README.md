# Loopz Pre-App Audit

هذا المجلد هو المرجع الرسمي لمراجعة Loopz قبل بدء بناء تطبيق React Native / Expo.

## الملفات

- [AUDIT_PLAN.md](./AUDIT_PLAN.md): خطة المراجعة الكاملة ومراحل القبول.
- [SHARED_PROGRESS.md](./SHARED_PROGRESS.md): ملف المتابعة المشترك وتبادل الأدوار بين ChatGPT وClaude.
- [CLAUDE_HANDOFF.md](./CLAUDE_HANDOFF.md): تعليمات البدء والتنسيق الموجهة إلى Claude.

## الأدوار

- **المالك وصاحب القرار:** أحمد.
- **المراجع الخارجي:** ChatGPT — قراءة، تحقق، اختبارات غير مغيرة، تسجيل النتائج، ومراجعة تنفيذ Claude.
- **المنفذ:** Claude — تعديل الكود والملفات والإعدادات بعد اعتماد المهمة، ثم تقديم الأدلة.
- **المرجع المشترك:** `SHARED_PROGRESS.md`.

## قواعد أساسية

1. لا تعديل مباشر على `main`.
2. لا Merge أو Deploy أو Migration أو حذف ملفات دون موافقة أحمد.
3. ChatGPT لا يكتب كود التطبيق ولا ينفذ إصلاحات.
4. Claude لا يبدأ إصلاحاً قبل وجود مهمة واضحة ومعيار قبول في ملف المتابعة.
5. اختبارات الأمن النشطة تكون على Preview أو Staging فقط.
6. يمنع وضع أسرار أو Tokens أو بيانات مستخدمين في ملفات التوثيق أو السجلات.
7. لكل مشكلة رقم موحد من الشكل `LOOPZ-AUD-0001`.
8. لا تعد المشكلة مغلقة حتى يعيد ChatGPT التحقق منها ويضع الحالة `VERIFIED`.
9. أثناء جلسة عمل نشطة، يحدث الطرف صاحب الدور ملف المتابعة كل 10 دقائق كحد أقصى أو عند إنجاز خطوة مهمة.
10. يجب قراءة أحدث نسخة من الملف قبل كل تحديث لتجنب التعارض.

## الفروع

- فرع التوثيق والتنسيق: `docs/pre-app-audit`.
- فروع إصلاحات Claude: `audit/phase-XX-short-name`.
- يبقى `main` دون تغيير حتى اعتماد أحمد.
