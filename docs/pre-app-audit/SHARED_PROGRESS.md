## الأدوار

### ChatGPT — Reviewer and Technical Gate

- يقرأ ويفحص ويشغل اختبارات غير مغيرة.
- يسجل المشكلات ومعايير القبول.
- يراجع Diff ونتائج الاختبار.
- يضع `VERIFIED` أو `CHANGES_REQUESTED`.
- بعد النجاح يجيز الدمج إلى `audit/integration`.
- عند اكتمال جميع البوابات يصدر قرار `GO / GO WITH CONDITIONS / NO-GO`.
- لا يكتب كود التطبيق أو ينفذ الإصلاحات.

### Claude — Executor

- ينشئ فرعاً مستقلاً لكل مجموعة إصلاحات.
- يعدل الكود والاختبارات والتوثيق وفق المهمة المسجلة.
- يشغل Build والاختبارات ويقدم الأدلة وCommit SHA.
- يضع `READY_FOR_REVIEW`.
- بعد `VERIFIED` يدمج إلى `audit/integration` دون الرجوع إلى أحمد.
- لا يضع `VERIFIED` لنفسه.
- لا يغير `main` أو Production أثناء مراحل التدقيق.

## الاستقلالية وحدود المخاطر

لا تحتاج موافقة أحمد في:

- الفحص والاختبار.
- إنشاء الفروع وPull Requests.
- إصلاحات الكود والتصميم والأداء والأمان.
- حذف كود ميت مثبت على فرع العمل.
- Preview deployments.
- دمج المهام المتحققة في `audit/integration`.
- تغييرات Staging الإضافية والقابلة للرجوع بعد وجود خطة اختبار.

تتوقف المهمة فقط عند:

- حذف بيانات Production.
- Migration تدميرية أو غير قابلة للرجوع على Production.
- كشف أسرار أو حادث أمني جارٍ.
- هدف غير محدد قد يؤثر في بيانات المستخدمين.
- حاجة لصلاحية غير متاحة.

عند اكتمال جميع البوابات، يعتمد ChatGPT القرار التقني النهائي وفق `AUDIT_PLAN.md` دون إدخال أحمد في دورة الإصلاح اليومية.
